# 主界面设置分组与保存策略-收尾文档

## 1. 目标与背景

本轮收尾聚焦两件事：

1. 主界面设置项数量增多后，重构信息架构，降低理解和误操作成本；
2. 优化“保存设置”交互，避免“保存即重置倒计时”带来的突兀体验。

---

## 2. 最终交付结论

### 2.1 主界面分组重构（已完成）

主窗口设置区已按用户心智拆分为四组：

1. **护眼策略（核心）**
   - 休息间隔
   - 休息时长
   - 预提醒开关
   - 锁屏处理（正常显示/暂停倒计时/跳过休息）

2. **休息窗口与约束**
   - 强制休息模式
   - 黑屏/图片轮播
   - 图片文件夹
   - 查看统计入口

3. **统计与数据**
   - 启用电脑使用统计
   - 指针移动距离（高级）

4. **系统与维护**
   - 开机自启动
   - 日志级别
   - 安全维护（改密/重置）
   - 保存相关按钮

> 特别调整：安全相关操作已从底部操作区移入“系统与维护”卡片。

### 2.2 保存交互优化（已完成）

采用“**1 主 + 1 次**”双按钮方案：

- **保存所有设置**（主按钮）
  - 保存全部配置
  - **不重置当前倒计时**
  - 时间策略在下个周期生效

- **立即应用计时策略**（次按钮）
  - 保存配置并立即按新策略生效
  - 直接重启主倒计时
  - 按确认方案：**无二次确认**

### 2.3 可感知提示增强（已完成）

保存时根据“时间策略是否变化”给出差异化反馈：

- 若仅点击“保存所有设置”且时间策略有变化：
  - Toast：`✅ 设置已保存（下个周期生效，当前倒计时不变）`
- 若时间策略无变化：
  - Toast：`✅ 设置已保存`
- 若点击“立即应用计时策略”：
  - Toast：`✅ 设置已保存并立即应用计时策略`

## 5. 当前交互规则（对外统一口径）

1. 日常调整优先使用“保存所有设置”；
2. 仅在用户希望立即按新策略计时时，点击“立即应用计时策略”；
3. 不再出现“改了非关键项却自动重置倒计时”的体验问题。
