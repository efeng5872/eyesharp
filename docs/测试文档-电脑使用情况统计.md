# EyeSharp 电脑使用情况统计测试文档

## 一、测试范围

### 1.1 功能测试范围

| 模块 | 测试内容 | 优先级 |
|------|---------|--------|
| **输入监控服务** | 键盘钩子、鼠标钩子、状态检测 | P0 |
| **数据库访问层** | CRUD操作、加密、事务 | P0 |
| **统计服务** | 数据聚合、查询、导出 | P0 |
| **UI展示** | 图表显示、数据绑定、交互 | P1 |
| **数据清理** | 自动清理、过期数据处理 | P1 |
| **异常处理** | 降级模式、错误恢复 | P1 |

### 1.2 测试类型划分

| 类型 | 范围 | 自动化 |
|------|------|--------|
| 单元测试 | 所有服务类、工具类 | 是 |
| 集成测试 | 服务间交互、数据库操作 | 是 |
| 端到端测试 | 完整用户使用流程 | 否（人工） |
| 性能测试 | 长时间运行、大数据量 | 部分自动 |
| 安全测试 | 加密验证、数据隔离 | 是 |

## 二、测试环境

### 2.1 硬件要求

```
最低配置:
```

| 环境 | 版本 | 说明 |

| .NET Runtime | 8.0.x | 必需 |
| 安全软件 | - | 测试被拦截场景 |

### 2.3 测试数据准备

```csharp
// 测试数据生成器
public class TestDataGenerator
{
    public static List<HourlyActivityRecord> GenerateHourlyData(int days)
    {
        var records = new List<HourlyActivityRecord>();
        var random = new Random();
        var startDate = DateTime.Now.AddDays(-days);

        for (int d = 0; d < days; d++)
        {
            for (int h = 0; h < 24; h++)
            {
                records.Add(new HourlyActivityRecord
                {
                    Hour = startDate.AddDays(d).AddHours(h),
                    ActiveSeconds = random.Next(0, 3600),
                    IdleSeconds = random.Next(0, 3600),
                    KeyPressCount = random.Next(0, 10000),
                    MouseMoveDistance = random.Next(0, 100000),
                    MouseLeftClickCount = random.Next(0, 1000),
                    MouseRightClickCount = random.Next(0, 500),
                    MouseMiddleClickCount = random.Next(0, 100),
                    MouseWheelScrollCount = random.Next(0, 200)
                });
            }
        }
        return records;
    }
}
```
