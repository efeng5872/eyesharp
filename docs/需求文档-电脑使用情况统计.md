# EyeSharp 电脑使用情况统计需求文档

## 一、需求概述

在现有护眼统计基础上，增加电脑使用情况的统计分析功能，帮助用户了解自己的工作习惯和用眼健康关联。

## 二、功能类需求

### 2.1 数据采集模块

#### 2.1.1 用户活跃度检测
- **功能描述**: 通过检测键盘鼠标活动判断用户空闲/活跃状态
- **业务逻辑**:
  - 定时检测（每5秒）键盘鼠标最后活动时间与当前时间差
  - 空闲阈值：5分钟无输入视为空闲
  - 记录状态变化时间点（空闲开始、活跃开始）
  - 不记录具体按键内容，仅记录"有活动/无活动"状态

#### 2.1.2 输入设备使用统计
- **功能描述**: 统计键盘鼠标的详细使用数据
- **业务逻辑**:
  - **键盘统计**:
    - 记录键盘按键总次数
    - 不记录具体按键内容，仅计数
    - 按小时/日汇总
  - **鼠标统计**:
    - 鼠标移动距离（像素数，可选转换为米）
    - 左键点击次数
    - 右键点击次数
    - 中键/滚轮点击次数
    - 滚轮滚动次数
  - **技术实现**:
    - 使用 Windows Low Level Hooks (WH_KEYBOARD_LL, WH_MOUSE_LL)
    - 在单独线程中处理输入事件，避免阻塞UI
    - 内存中实时计数，定期批量写入

#### 2.1.2 电脑使用时长统计
- **功能描述**: 统计每日电脑实际使用时长
- **业务逻辑**:
  - 程序启动即开始计时
  - 锁屏期间暂停计时
  - 空闲超过5分钟暂停计时
  - 区分"总开机时长"和"实际活跃时长"

#### 2.1.3 锁屏行为分析（复用现有逻辑）
- **功能描述**: 扩展现有锁屏检测，增加统计分析
- **业务逻辑**:
  - 记录每次锁屏开始/结束时间
  - 计算锁屏时长
  - 统计每日锁屏次数
  - 关联护眼休息与锁屏的关系（休息后是否锁屏等）

### 2.2 数据存储模块

#### 2.2.1 新增数据模型
```csharp
// 小时级活跃度记录
public class HourlyActivityRecord
{
    public DateTime Hour { get; set; }          // 小时时间段 (如 2026-03-08 14:00)
    public int ActiveSeconds { get; set; }      // 活跃秒数
    public int IdleSeconds { get; set; }        // 空闲秒数
    public int LockScreenSeconds { get; set; }  // 锁屏秒数
    public int LockScreenCount { get; set; }    // 锁屏次数

    // 输入设备统计
    public int KeyPressCount { get; set; }          // 键盘按键次数
    public long MouseMoveDistance { get; set; }     // 鼠标移动距离（像素）
    public int MouseLeftClickCount { get; set; }    // 鼠标左键点击次数
    public int MouseRightClickCount { get; set; }   // 鼠标右键点击次数
    public int MouseMiddleClickCount { get; set; }  // 鼠标中键点击次数
    public int MouseWheelScrollCount { get; set; }  // 鼠标滚轮滚动次数
}

// 扩展每日统计
public class DailyUsageStatistics
{
    public DateTime Date { get; set; }
    public int TotalBootSeconds { get; set; }       // 总开机时长（程序运行时长）
    public int ActiveSeconds { get; set; }          // 实际活跃时长
    public int IdleSeconds { get; set; }            // 空闲时长
    public int LockScreenSeconds { get; set; }      // 锁屏总时长
    public int LockScreenCount { get; set; }        // 锁屏次数
    public List<HourlyActivityRecord> HourlyData { get; set; }  // 24小时详细数据

    // 输入设备日汇总
    public int TotalKeyPressCount { get; set; }         // 总按键次数
    public long TotalMouseMoveDistance { get; set; }    // 总鼠标移动距离（像素）
    public int TotalMouseLeftClickCount { get; set; }   // 总左键点击
    public int TotalMouseRightClickCount { get; set; }  // 总右键点击
    public int TotalMouseMiddleClickCount { get; set; } // 总中键点击
    public int TotalMouseWheelScrollCount { get; set; } // 总滚轮滚动

    // 计算属性
    public double MouseMoveDistanceMeters => TotalMouseMoveDistance / 3779.5; // 96DPI下转换为米
    public double AvgKeyPressPerHour => TotalBootSeconds > 0 ? TotalKeyPressCount / (TotalBootSeconds / 3600.0) : 0;
    public double AvgClickPerHour => TotalBootSeconds > 0 ? (TotalMouseLeftClickCount + TotalMouseRightClickCount) / (TotalBootSeconds / 3600.0) : 0;
}
```

#### 2.2.2 存储要求
- 本地 JSON 文件存储（`usage_statistics.json`）
- 保留最近 90 天小时级数据
- 保留最近 365 天日级汇总数据

### 2.3 统计展示模块

#### 2.3.1 数据查询接口
```csharp
public interface IUsageStatisticsService
{
    // 获取今日使用情况
    DailyUsageStatistics GetTodayUsage();

    // 获取本周汇总
    DailyUsageStatistics GetWeekUsage();

    // 获取本月汇总
    DailyUsageStatistics GetMonthUsage();

    // 获取最近N天每小时数据（用于趋势图）

    List<DailyUsageStatistics> GetDailyUsage(int days);

```

#### 2.3.2 统计界面设计
**新增"电脑使用"标签页在统计窗口中**

- **今日概览卡片**:
  - 时间统计：
    - 开机时长：X小时X分
    - 实际活跃：X小时X分（占比）
    - 空闲时长：X小时X分
    - 锁屏次数：X次，总时长X小时X分

  - X轴：0-23小时

- **输入活动热力图**:
  - 24小时键盘点击热力图
  - 24小时鼠标点击热力图

  - 日期、活跃时长、锁屏次数、效率指数（活跃/开机比）

  - 支持按日/周/月视图切换
  - 点击行可查看该日24小时详细数据

### 2.4 关联分析模块

#### 2.4.1 护眼与使用习惯关联
- 计算"用眼强度指数" = 活跃时长 / 休息次数
- 提示用户：工作X小时，建议休息Y次，实际休息Z次
- 锁屏后是否主动休息的关联分析

## 三、非功能类需求

### 3.1 性能要求
- 输入检测使用Windows钩子，CPU占用 < 2%
- 数据保存异步进行，不阻塞UI
- 统计查询响应时间 < 100ms
- 内存缓存策略：输入事件先计入内存，每60秒批量写入磁盘
- 峰值内存占用 < 50MB

### 3.2 安全与隐私
- 仅本地存储，不上传任何数据
- **不记录具体按键内容**（如输入了什么文字），仅记录按键次数
- **不记录鼠标位置坐标**，仅记录移动距离和点击次数
- 数据文件加密存储（可选，建议开启）
- 用户可在设置中关闭输入统计功能

### 3.3 日志要求
- 记录服务启动/停止
- 记录数据采集异常
- 记录数据保存失败详情

### 3.4 兼容性
- Windows 10/11 支持
- 支持多显示器环境

## 四、需求澄清问答

**Q1: 空闲检测是否需要在锁屏时继续？**
A: 不需要，锁屏时暂停所有检测，锁屏时长单独统计。

**Q2: 跨天使用如何处理？**
A: 以自然日（0:00-23:59）为统计单位，跨天使用按实际时间点分割到两天。

**Q3: 程序意外崩溃数据是否丢失？**
A: 每小时自动保存一次，最大丢失1小时数据。

**Q4: 用户手动退出程序期间是否统计？**
A: 不统计，仅统计程序运行期间的数据。

**Q5: 多用户系统如何处理？**
A: 按Windows用户分别存储数据文件。

**Q6: 是否会记录我输入的密码等敏感信息？**
A: 不会。系统只记录"按键次数"这个计数，完全不记录按了哪个键。例如：你输入"password"和"123456"都会被记录为8次按键，但无法从数据中反推你输入了什么。

**Q7: 鼠标移动距离如何计算？**
A: 通过Windows钩子获取鼠标坐标变化，计算欧几里得距离。例如从(100,100)移动到(200,200)，移动距离为141像素。96 DPI下约等于3.75厘米。

**Q8: 输入统计能否关闭？**
A: 可以。在设置中提供"启用输入统计"开关，关闭后不再记录键盘鼠标数据，但时间统计（活跃/空闲/锁屏）仍继续。

**Q9: 哪些安全软件可能拦截输入检测？**
A: 可能拦截的软件包括：360安全卫士、腾讯电脑管家、卡巴斯基、Windows Defender（可能提示风险提示）。建议在软件设置中将EyeSharp添加到白名单。

**Q10: 数据量会有多大？**
A: 估算：每小时记录约100字节，每日约2.4KB，每年约900KB。包含90天详细数据+365天汇总数据，总文件大小约500KB。

## 五、技术风险评估

| 风险点 | 可能性 | 影响 | 缓解措施 |
|--------|--------|------|----------|
| 输入检测被安全软件拦截 | 高 | 高 | 使用Windows标准API，提供白名单说明； gracefully degrade（优雅降级） |
| 低级别钩子被其他程序抢占 | 中 | 中 | 定期检测钩子是否正常工作，失败时重试 |
| 数据文件过大 | 中 | 中 | 自动清理90天前小时级数据；压缩存储 |
| 多实例冲突 | 低 | 中 | 文件访问加锁机制 |
| 隐私合规风险 | 中 | 高 | 明确告知用户收集内容；提供关闭选项；不记录敏感内容 |
